**Tic-Tac-Toe Game 🟢❌**

A simple Tic-Tac-Toe game built using Python and Tkinter. This interactive GUI-based game allows two players to play against each other on the same computer.

**Features**

User-friendly Tkinter GUI

Two-player mode

Win detection for rows, columns, and diagonals

Alerts for winner or tie

Easy to extend for AI opponent in the future
